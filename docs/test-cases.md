## 3. 상세

### TC-001 캐릭터 10단계와 반지름 정의
- **목적**: 캐릭터 단계 수와 크기 순서가 사양과 같은지 확인
- **사전 조건**: 게임 로드 완료
- **절차**: 1) `RADII`, `IMGS`, `META` 를 읽는다
- **기대 결과**: RADII = [16, 22, 29, 36, 44, 53, 63, 74, 87, 104], 단조 증가. IMGS·META 각 10개

### TC-002 드롭 캐릭터는 0~4단계 중 무작위
- **목적**: 드롭 후보 단계의 범위와 분포 확인
- **절차**: 1) 난수를 0, 0.999999 로 고정해 `randTier()` 호출 2) 실제 난수로 2000회 호출 3) 게임 초기화
- **기대 결과**: 1) 각각 0, 4 2) 모두 0~4 정수이고 0~4가 전부 나타남 3) 현재·다음 캐릭터가 0~4

### TC-003 포인터 이동/누름으로 조준 위치 갱신
- **절차**: 1) 논리 x=100 위치로 pointermove 2) x=300 위치로 pointerdown
- **기대 결과**: 1) aimX≈100 2) aimX≈300, 캐릭터는 생성되지 않음

### TC-004 포인터를 떼면 그 위치에 드롭
- **절차**: 1) 논리 x=150 위치에서 pointerup
- **기대 결과**: 현재 단계의 캐릭터 1개가 x≈150 에 생성됨

### TC-005 ←/→ 키로 조준 12px 이동
- **사전 조건**: aimX=200
- **절차**: 1) ← 1회 2) → 2회
- **기대 결과**: 1) 188 2) 212

### TC-006 Space/↓ 키로 드롭, 기본 동작 차단
- **절차**: 1) Space 2) 600ms 대기 후 ↓
- **기대 결과**: 각각 캐릭터 1개씩 생성, 두 이벤트 모두 `defaultPrevented`

### TC-007 드롭 위치를 벽 안쪽으로 제한
- **사전 조건**: 현재 캐릭터 4단계 (r=44)
- **절차**: 1) aimX=-500 에서 드롭 2) 600ms 후 aimX=5000 에서 드롭
- **기대 결과**: 1) x = BOX_L+44 = 58, y = DROP_Y 2) x = BOX_R−44 = 382

### TC-008 키 조준은 이동 범위 밖으로 누적되지 않음
- **사전 조건**: 현재 캐릭터 0단계 (r=16), aimX=220
- **절차**: 1) ← 40회 (480px, 왼쪽 벽을 넘는 입력) 2) → 1회 3) 화면에 그려진 조준 캐릭터 위치 확인
- **기대 결과**: 조준 캐릭터 x = BOX_L+16+12 = 42 (왼쪽 끝에서 즉시 한 칸 이동)

### TC-009 드롭 후 550ms 쿨다운과 다음 캐릭터 승계
- **절차**: 1) 드롭 2) 즉시 재드롭 3) 화면의 조준 캐릭터 불투명도 확인 4) 400ms 후 재드롭 5) 650ms 시점 불투명도 확인 후 재드롭
- **기대 결과**: 1) 현재 캐릭터 = 직전 "다음" 캐릭터 2) 무시 3) 0.35 4) 무시 5) 불투명도 1, 드롭 성공 (총 2개)

### TC-010 같은 단계가 닿으면 다음 단계 1개로 합체
- **절차**: 1) 2단계 캐릭터 두 개를 6px 겹치게 배치 2) 물리 스텝 진행
- **기대 결과**: 3단계 캐릭터 1개만 남고 두 중심의 중점(±3px)에 위치, 점수 6

### TC-011 서로 다른 단계는 합체하지 않음
- **절차**: 1) 1단계와 2단계를 겹치게 배치 2) 60스텝 진행
- **기대 결과**: 1·2단계 모두 남음, 점수 0

### TC-012 한 캐릭터는 한 번만 합체 (3개 동시 접촉)
- **절차**: 1) 0단계 a, b, c 를 만들고 (a,b), (a,c), (b,c) 충돌을 한 이벤트로 전달
- **기대 결과**: 1단계 1개 + 0단계 1개가 남고 점수 1

### TC-013 단계별 합체 점수 (t+1)(t+2)/2
- **절차**: t = 0~8 각각 같은 단계 두 개의 충돌을 전달
- **기대 결과**: 점수 = (t+1)(t+2)/2 (1, 3, 6, 10, 15, 21, 28, 36, 45), 결과 단계 t+1

### TC-014 최고 단계 두 개 합체 시 소멸 + 200점 보너스
- **절차**: 9단계 두 개의 충돌을 전달
- **기대 결과**: 캐릭터 0개, 점수 255 (55 + 200), "세이렌 보너스 +200" 문구 이펙트 존재

### TC-015 합체 이펙트 (파티클 14개 + 링)
- **절차**: 1) 2단계 합체 2) 30프레임(≈1초) 진행
- **기대 결과**: 1) 파티클 14, 링 1, 새 캐릭터 pop=1 2) 이펙트 모두 소멸

### TC-016 HUD에 점수·최고 기록·다음 캐릭터 표시
- **절차**: 1) 점수 37, 최고 100 으로 1프레임 렌더 2) 점수 150 으로 1프레임 렌더
- **기대 결과**: 1) "점수", "37", "최고 100", "다음" 텍스트와 (W−40, 56) 위치의 다음 캐릭터 2) "최고 150"

### TC-017 저장된 최고 기록을 시작 시 불러옴
- **사전 조건**: 변형 stored (저장값 1234)
- **기대 결과**: 시작 시 best = 1234

### TC-018 게임 오버 시 최고 기록 갱신·저장
- **절차**: 1) best=50, 점수 80 으로 게임 오버 2) 재시작 후 점수 30 으로 게임 오버
- **기대 결과**: 1) 저장값 "80" 2) 저장값 "80" 유지, best=80

### TC-019 저장소 사용 불가 환경에서도 정상 동작
- **사전 조건**: 변형 nostorage
- **절차**: 1) 시작 상태 확인 2) 점수 10 으로 게임 오버
- **기대 결과**: 1) 시작 오류 없음, best=0 2) 예외 없이 게임 오버, 메모리상 best=10

### TC-020 위험선 초과 상태 2.2초 지속 시 게임 오버
- **사전 조건**: 생성 5초 지난 정지 캐릭터(5단계)가 위험선에 걸침
- **절차**: 33ms 프레임을 60회(1.98초) → 10회 더(2.31초)
- **기대 결과**: 1.98초에는 진행 중, 2.31초에는 게임 오버

### TC-021 생성 1.2초 이내 캐릭터는 판정 제외
- **절차**: 방금 생성한 정지 캐릭터를 위험선에 두고 30프레임(≈1초)
- **기대 결과**: 위험 시간 0

### TC-022 움직이는 캐릭터(속도≥1.5)는 판정 제외
- **절차**: 중력 0, 위험선 위 캐릭터를 매 프레임 속도 3 으로 움직이며 90프레임
- **기대 결과**: 게임 오버 아님, 위험 시간 0

### TC-023 위험 해소 시 타이머가 2배 속도로 감소
- **절차**: 1) 위험 상태 30프레임 2) 캐릭터 제거 후 10프레임
- **기대 결과**: 1) 0.99초 2) 0.99 − 10×0.066 = 0.33초

### TC-024 게임 오버 화면과 진행 정지
- **절차**: 1) 캐릭터 1개, 점수 42 로 게임 오버 2) 20프레임 진행 3) 드롭 시도
- **기대 결과**: 1) 결과 화면 표시, "점수 42", "최고 기록" 문구 2) 캐릭터 위치 불변, 조준 캐릭터 미표시 3) 캐릭터 수 불변

### TC-025 다시 하기로 초기 상태 복귀
- **절차**: 1) 점수 99 로 게임 오버 2) "다시 하기" 클릭 3) 드롭
- **기대 결과**: 2) 결과 화면 숨김, 점수 0, 위험 시간 0, 캐릭터 0, 벽 3개 3) 드롭 성공

### TC-026 화면 크기에 맞춘 비율 유지 스케일과 DPR 대응
- **절차**: 창 크기·DPR 을 375×667@3, 1920×1080@1, 1024×600@2 로 바꾸고 resize 이벤트 발생
- **기대 결과**: 배율 = min((w−16)/440, (h−16)/720), CSS 크기 = 440·배율 × 720·배율 (창 안에 들어감), 캔버스 픽셀 = round(CSS 크기 × DPR)

### TC-027 단일 파일 구성 (엔진·이미지 내장)
- **기대 결과**: 외부 스크립트 0, `Matter.version` = 0.19.0, 이미지 10종 모두 data URI 이며 디코딩 성공, 외부 링크는 fonts.googleapis.com 뿐

### TC-028 오프라인(폰트 미수신)에서도 시작·렌더링
- **사전 조건**: 네트워크 차단 (러너 기본)
- **기대 결과**: 시작 오류 없음, body 폰트에 시스템 대체 폰트 지정, 1프레임 렌더 시 HUD 텍스트와 캐릭터가 그려지고 오류 없음

### TC-029 이미지 미로딩 시 색상 원으로 대체
- **절차**: 1) 3단계 캐릭터 그리기 2) 3단계 이미지를 로드 안 된 이미지로 바꿔 그리기
- **기대 결과**: 1) drawImage 1회, 원 0개 2) drawImage 0회, 원 1개

### TC-030 하단 진화 단계 10종 표시
- **절차**: 1프레임 렌더
- **기대 결과**: y = BOX_B+36 에 0~9단계가 순서대로 그려지고 "›" 9개

### TC-031 위험선 표시 및 위험 시 강조
- **절차**: 1) 평상시 1프레임 2) 위험 시간 1초 상태에서 1프레임
- **기대 결과**: 1) [10,8] 점선 1개, 색 rgba(230,90,100,0.35) 2) 색 rgba(230,60,70,α)

### TC-032 프레임 간격 33ms 상한
- **절차**: 1) 직전 프레임과 5000ms 간격으로 frame 호출 2) 16ms 간격으로 호출
- **기대 결과**: 물리 엔진 갱신 간격 1) 33ms 2) 16ms

### TC-033 requestAnimationFrame 기반 연속 루프
- **절차**: 1) 시작 시 rAF 등록 내역 확인 2) 1프레임 실행
- **기대 결과**: 1) 첫 등록 콜백이 `frame` 2) 다음 프레임이 다시 등록됨

### TC-034 모바일 확대/스크롤/선택 방지
- **기대 결과**: viewport 에 `user-scalable=no`, `maximum-scale=1`. body 의 touch-action: none, overflow: hidden, user-select: none
